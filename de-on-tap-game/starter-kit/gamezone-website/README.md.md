# Hệ Thống Quản Lý Web Game GameZone

Đây là dự án **quản lý hệ thống** được phát triển nhằm *tối ưu hóa* quá trình vận hành và kiểm soát lỗi của trò chơi.

## Cấu trúc thư mục

| Thư mục | Nội dung mô tả |
| :--- | :--- |
| `docs` | Lưu trữ tài liệu hướng dẫn và cập nhật hệ thống |
| `media` | Chứa hình ảnh, logo chính thức của game |
| `logs` | Lưu trữ các file log lỗi và báo cáo tự động |

## Lệnh kiểm tra hệ thống

Dưới đây là câu lệnh dùng để liệt kê toàn bộ cấu trúc thư mục dự án:

```powershell
ls -Force
```
